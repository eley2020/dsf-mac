# DSF-MAC public reproduction release

This is the cleaned code-and-results release accompanying the patient-specific EEG seizure pre-warning study. It contains the mainline DSF-MAC scripts, the exact CHB-MIT Stage 3 configuration, compact result manifests, and publication figures.

## Reference result

CHB-MIT: 170 held-out seizure folds, 97.06% event sensitivity, 0.874 FAR/h, and 23.52 min mean warning time. The compact Stage 3 ablation reached 96.47% event sensitivity and 0.850 mean fold FAR/h with 244,379 parameters.

## Data and licensing

EEG recordings, EDF files, private annotations, caches, checkpoints, and temporary logs are intentionally excluded. Obtain data from the official sources and follow their terms. The code is released under the MIT License in `LICENSE`. The repository URL is `https://github.com/eley2020/dsf-mac`.
